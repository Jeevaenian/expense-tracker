EXPENSEFLOW - EXPENSE TRACKER FRONTEND

This is a standalone frontend website.

Included:
- index.html
- style.css

Run:
1. Extract the ZIP.
2. Open index.html in Chrome, Edge, or Firefox.
3. No npm installation is required.

Features shown:
- Available balance
- Income and expense summary
- Savings
- Cash flow chart
- Monthly budget
- Category spending
- Recent transactions
- Responsive mobile layout

The Add Transaction and Export Report buttons currently show demo messages.
They can be connected later to a backend/database/API.
